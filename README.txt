BLACKMAMBA MIC RAINBOW RING

1. Abre index.html en un navegador moderno.
2. Pulsa "ACTIVAR MICRÓFONO".
3. Autoriza el acceso al micrófono.

Comportamiento:
- Sin audio: círculo perfecto.
- Con audio: el círculo se deforma según el espectro del micrófono.
- El color recorre todo el arcoíris.
- Tiene glow y suavizado visual.

Nota:
Algunos navegadores requieren HTTPS o localhost para permitir acceso al micrófono.
